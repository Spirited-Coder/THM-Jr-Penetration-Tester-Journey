# Module 1: Introduction to Cyber Security

## 🎯 Overview
This module establishes the foundational principles of cybersecurity, detailing the core security models used to protect enterprise data and the specific operational roles within the industry.

## 🛡️ Key Concepts Mastered

### 1. The CIA Triad
Every security risk can be mapped back to a failure in one of these three pillars:
* **Confidentiality:** Handled via encryption and tight access controls to keep data private.
* **Integrity:** Maintained through hashing and verification to ensure data isn't altered.
* **Availability:** Ensured through system redundancy and architecture resilience so systems stay online.

### 2. Operational Roles
* **Red Teaming (Offensive):** Simulating real-world attacks to identify weaknesses in an environment. (My primary path).
* **Blue Teaming (Defensive):** Monitoring, detecting, and mitigating threats to harden a network's posture.

## 🧠 Professional Takeaway
Cybersecurity is not an isolated technical puzzle; it is a business enablement tool. An effective penetration tester doesn't just "break into systems" for fun—they exploit weaknesses specifically to help organizations reinforce their Confidentiality, Integrity, and Availability.
